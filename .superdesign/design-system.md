# Gündoğdu — Gideros'ta hayat yavaşlar

Turkish family pension and restaurant introduction, independent PHP site. Homepage plus Odalar, Restoran, Galeri, İletişim. User authorizes implementation without interim design approval; only live deployment needs approval.

Adapt the Nature Inspired library's earthy editorial idea to a tranquil local coastal pension. User's explicit understated requirements override oversized industrial type, huge radii, noise and parallax from that inspiration.

Palette: warm limestone #F6F3EB, paper #FFFEFA, dark forest #244C45, deep sea #254B59, warm sand #C29562, ink #263D36, muted #68746C. Body Manrope (400/500/600); headings Cormorant Garamond (400/500), generous elegant editorial typography, not a luxury resort claim. Hero 80px desktop/46px mobile; titles 50px/36px. Spacing 8/16/24/32/48/80/112px. Mostly square photography with 3px corners, quiet pill buttons, thin rules. Wide 1240px content shell.

Top light header with original sunrise/bay SVG mark and Gündoğdu wordmark. Simple nav and forest booking button. Full-bleed actual Gideros panorama, left aligned poetic white heading 'Gideros’ta, / hayat yavaşlar.', tiny uppercase place eyebrow, restrained text and two CTAs. Photo is public Commons Gideros Bay1 by Makalp, CC BY-SA 3.0; must credit. Narrow cream intro strip. Editorial split introduction; accommodations cards only published API data, honest attractive empty state otherwise; restaurant editorial section with no invented food photos or services; forest green nature section, 2 licensed landscape photos, location/contact from API only. Clean footer and matching booking panel. No fake room/food/rating/amenity data, hardcoded contact details, or invented testimonials.

Reduced motion, subtle 20fps water overlay using BlackSea engine (not styling), accessible keyboard/mobile menu, 320px fit. Existing Yardımcı Asistan widget logic unchanged; site-scoped CSS theme. API-owned business name/contact/rooms/menu/gallery/campaigns only. Beautiful useful unpublished states.
